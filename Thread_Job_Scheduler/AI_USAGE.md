# AI USAGE

ChatGPT

## 2. ลักษณะการใช้งาน AI

อธิบายแนวคิดเกี่ยวกับ Java Thread, การทำงานพร้อมกัน (Concurrency), BlockingQueue, Semaphore และการจัดตารางงาน (Scheduling)

ช่วยวิเคราะห์ข้อผิดพลาดที่อาจเกิดขึ้นและแนวทางปรับปรุงโค้ด

ช่วยอธิบายและวิเคราะห์ผลการทดลองจากการตั้งค่าการทำงานที่แตกต่างกัน

## 3. การตรวจสอบ

ตรวจสอบคำอธิบายและแนวทางที่ได้รับจาก AI โดยเปรียบเทียบกับข้อกำหนดของงาน และทดลองรันโปรแกรม ระหว่างการพัฒนาโปรเจกต์ ได้มีการใช้ ChatGPT ช่วยตรวจสอบโค้ดในคลาส Job.java โดย AI เคยแนะนำให้เพิ่ม synchronized ให้กับ Getter และ Setter เลยได้ตั้งข้อสงสัยว่าจำเป็นต้องใช้ synchronized กับทุกเมธอดหรือไม่ 

จึงตรวจสอบข้อกำหนดของโปรเจกต์และลักษณะการเข้าถึงข้อมูลร่วมกันเพิ่มเติม
พบว่าไม่ควรเพิ่ม synchronized ให้กับทุกเมธอดโดยอัตโนมัติ แต่ควรพิจารณาตามความจำเป็นในการป้องกันการเข้าถึงข้อมูลพร้อมกัน
